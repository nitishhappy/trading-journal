# Update README Before Git Push

## Rule
Whenever you are about to execute a `git push` command, you MUST first ensure that the `README.md` file has been updated to reflect the latest changes, features, or architectural decisions you have made during the session.

## Workflow
1. Before committing and pushing your final changes, review the `README.md`.
2. Update the `README.md` with a summary of the new features or modifications if they are not already documented.
3. Once the `README.md` is updated and saved, you may proceed with the `git commit` and `git push` commands.
